# Очистка и анализ данных о продажах автомобилей в Казахстане за 2019 год

## Описание

Автодилерский холдинг хочет оценить позицию своего автоцентра «Меркур Авто» на рынке Казахстана и найти точки роста. 
Исходная выгрузка по продажам за девять месяцев 2019 года содержит нестандартные форматы, неявные дубликаты, сдвинутые 
столбцы и аномалии, поэтому без предварительной подготовки её нельзя использовать для анализа. В рамках проекта данные 
очищены и приведены к нужным типам, после чего проведён разведочный анализ рынка и сравнение показателей автоцентра с 
общерыночными.

## Структура проекта

```
.
├── cleaning.py             # очистка данных
├── eda_mercur.py           # EDA рынка и анализ Mercur Auto
├── autokz2019.csv          # исходные данные
├── autokz2019_clean.csv    # очищенный датасет
├── figs/                   # графики
├── docs/                   # отчёт по проекту
└── requirements.txt        # зависимости
```

## Запуск

```bash
pip install -r requirements.txt
python cleaning.py       # создаёт autokz2019_clean.csv
python eda_mercur.py     # строит графики в figs/ и выводит KPI
```

## Данные

- Исходный файл: 39 966 строк, 25 столбцов.
- Итоговый датасет: 16 434 строки, 19 столбцов.

## Этапы очистки

- **Столбцы:** удалены 7 малоинформативных, остальные переименованы на английский.
- **Дубликаты и пропуски:** удалены явные дубликаты и строки без количества, объединены неявные дубликаты в названиях компаний.
- **Кодирование категорий:** страны переведены в ALPHA-3, топливо закодировано как F / D / E / HYB, привод сведён к 4WD / FWD / RWD / 2WD, коробка передач — к «Автомат» и «Механика».
- **Объём двигателя:** распарсены строковые значения, исправлены ошибки (мощность вместо объёма у Jaguar, аномалии Chevrolet Niva).
- **Структурные ошибки:** исправлены строки со смещением значений между столбцами (Renault).
- **Аномалии:** возвраты (`quantity < 0`) и оптовые партии (`quantity > 10`) помечены флагами `is_return` и `is_bulk`.
- **Дата:** из года и месяца собран столбец `sale_date` (последний день месяца).
- **Типы данных:** `datetime`, числовые типы, `category` для топлива, привода, коробки, сегмента и класса.

## Основные результаты

- Всего продано 30 280 автомобилей на сумму 676,6 млн USD, на топ-5 брендов приходится около 69% продаж.
- Доля рынка «Меркур Авто» составляет 1,2% по количеству и 2,2% по выручке, а средняя цена автомобиля 39,3 тыс. USD при рыночной 22,3 тыс. USD.
- С июня в данных нет продаж Volkswagen, из-за чего месячные продажи автоцентра упали с 57–89 до 8–14 автомобилей.
